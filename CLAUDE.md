# Волны Эллиотта — Android-приложение (памятка для Claude)

Репозиторий: github.com/Biohazard-cmd/elliott-waves (приватный). Прочитай целиком перед любой работой. Здесь — как устроен проект, как собирать, что уже проверено и как работать с владельцем.

## Владелец и как с ним работать

- **Егор** (часто в дороге, бывает без интернета, работает с телефона Android). Торгует на Мосбирже через Т-Инвестиции, изучает волны Эллиотта по книге Пректера и Фроста «Волновой принцип Эллиотта». **Не программист** — описывает словами, что хочет видеть; отвечать по-русски, просто, без кода в ответах.
- **Правила работы (обязательно):**
  1. По умолчанию всё «как по книге». Всё, что сверх книги, — **отдельная опция** (дополнение), по умолчанию выключена.
  2. «**Прежде чем что-то внедрять — расскажи мне**». Новые функции: сначала объяснить план (а если это фильтр/правило торговли — сначала проверить на истории и показать цифры), внедрять после согласия. Явные просьбы «сделай …» и исправления ошибок — делать сразу.
  3. «**Без сборки**» / «только расскажи» — тогда не собирать APK, только объяснить или внести правки.
  4. Торговые фильтры внедрять **только если проверка на истории 65 бумаг подтвердила** (обе половины истории, доходность на общем счёте, просадка, серии стопов). Честно писать, что не прошло.
  5. После изменений: проверить (UI-тест на моках), поднять версию, собрать APK, прислать файл и коротко объяснить, что изменилось и где это найти.
- **Безопасность:** токен T-Invest API — только для чтения, хранится только на телефоне. **Никогда** не просить прислать токен, не писать его в логи и выгрузки (в журнале нет токена, номеров счетов и сумм). «Ключ для торговли пока не трогаем» — приложение само не торгует на реальном счёте, роботы — виртуальные. MetaTrader 5 больше не нужен (папка mt5 — история).

## Устройство

Android-приложение = WebView со страницей из `android/assets`. Пакет `ru.elliottwaves.app`.

| Файл | Что внутри |
|---|---|
| `android/assets/index.html` | разметка и CSS |
| `android/assets/app.js` | весь интерфейс: график (canvas), панель «Сейчас», настройки, наборы (PRESETS), дневник, роботы (UI), тренажёр, подсказки. Версия — `const APP_VER = '…'` |
| `android/assets/engine2.js` | движок `EW2`: зигзаг, подсчёт волн (импульс, клин, зигзаг, флэт, треугольник), сетапы входа, бэктест, фильтры (тренд старшей степени, рынок, AO 5/34, SMA200, «осторожный рынок»), доливка Вильямса, безубыток, подсказки |
| `android/assets/data.js` | `EWData`: API Т-Инвестиций (через мост Android), хранилище, дивиденды, сканер, индекс рынка, фоновая проверка `checkAll`, уведомления `events`, **роботы** `robotStep` (виртуальные счета) |
| `android/assets/worker.html` | страница фоновой проверки (запускается без окна) |
| `android/src/.../MainActivity.java` | WebView приложения |
| `android/src/.../Bridge.java` | мост JS↔Android: HTTP-запросы `postAsync` (ответ через Handler главного потока!), уведомления (обычный и тихий канал), файлы, «Загрузки», сертификат Минцифры |
| `android/src/.../CheckService.java` | JobService: фоновая проверка каждые 15+ мин, таймаут 9 мин |
| `android/src/.../WidgetProvider.java`, `WidgetService.java` | виджет на главном экране (`res/layout/widget.xml`, `widget_row.xml`, `res/xml/widget_info.xml`): заголовок + **листаемый список** (ListView через RemoteViewsService). Строки и «что открыть» по нажатию (`rows`, `opens`) готовит `EWData.widgetPush` (data.js), передаёт `Bridge.widgetUpdate`. Порядок: сигналы → роботы → остальные фазы → «не ясна». Обновляется после фоновой проверки и при смене темы. Шаблон PendingIntent у списка — без FLAG_IMMUTABLE (иначе не дойдёт бумага из строки; при targetSdk 31+ понадобится FLAG_MUTABLE) |
| `research/` | скрипты проверок на истории (Node.js) и UI-тесты |
| `legacy/`, `mt5/` | старые версии (веб-страница и индикатор MT5) — для истории |

## Сборка APK

Нужны: Java (JDK с `javac`, `jar`) и zip. Инструменты сборки уже лежат в папке `tools` этого репозитория (`aapt2_64` для Linux x86-64, `android.jar`, `dex-tools-v2.4` — dx 30.0.2, `uber-apk-signer-1.3.0.jar`); `build.sh` находит их сам.

```
# 1) поднять версию в android/assets/app.js: const APP_VER = '2.38'
# 2) собрать, VER_CODE — на 1 больше прошлого (2.37 = 78)
cd android && VER_CODE=79 bash build.sh
# готовый файл: android/build/out/app-aligned-debugSigned.apk → переименовать в ElliottWaves-<версия>.apk
```

Подпись — встроенный отладочный ключ uber-apk-signer. **Не менять способ подписи**, иначе новая версия не установится поверх старой (придётся удалять приложение и терять данные на телефоне).

## Что проверено на истории (дневки, 65 бумаг, 2019–2026) — решения

Портфель: риск 1% на сделку, позиция ≤25% капитала, свободные деньги в фонде денежного рынка.

- **Наборы роботов** (PRESETS в app.js): «Дневки · покупки (основной)» `d_long` и «(агрессивный)» `d_aggr` = основной + стоп под концом волны 2, после цели стоп под минимумами 5 свечей, доливка.
- **Фильтр AO 5/34 (Вильямс)** — вход, только если AO на стороне сделки: основной 22,9→24,8%/год. Включён в оба набора.
- **Доливка на 110% волны 1** (Вильямс): агрессивный заметно лучше, основной — смешанно. Включена в агрессивный.
- **Фильтр «SMA200 растёт»** (средняя 200 выше, чем 20 свечей назад): основной ~26,4%/год, просадка 12→8%, серия стопов 17→11; агрессивный (с доливками) ~32→38%/год, просадка 19→11%. Устойчив к сроку 5–60 дней. Включён в оба набора (2.21).
- **«Осторожный режим»** (индекс рынка выше SMA50) — меньше просадка, ниже доходность; опция, выключен.
- **Безубыток** (2.31): денег почти не добавляет, но сглаживает. 3×ATR: основной ~26,4%/год, просадка 8→6%, серия стопов 11→8, прибыльных 50→59%; агрессивный с доливками 37,9→38,7%/год, серия стопов 23→11. Устойчив при 2,5–4×ATR. По умолчанию — только подсказка; перенос стопа — опция; у роботов — кнопка на каждом счёте (2.32).
- **Не прошли:** стоп Вильямса «за вершину волны 1» (прибыль вдвое меньше); правило «100–140 свечей»; зона волны 5 по Джозефу; ADX, всплески объёма, «перегрев» за 3 месяца, OBV; клин на 4ч как фильтр часовых сигналов (хуже); сделка против клина на 1ч/4ч (минус), на дневках +0,22 R но всего 65 случаев.
- **Дивергенция на волне 5** (2.36, `research/div5.js`, опция движка `addDiv5Exit`, в интерфейсе не показана): выход после завершённой волны 5 по сделке, если AO 5/34 на ней слабее, чем на волне 3. Основной: R 212→217, но 26,4→25,7%/год, просадка 8→7%; агрессивный: R 493→466 (вторая половина 317→288), 31,5%/год без изменений, просадка 12→10%, серия стопов 23→19. Выход после любой завершённой волны 5 (`'all'`) — почти то же, т.е. сама дивергенция ничего не добавляет. **Не прошла** как торговое правило — оставлена только подсказка в «Подсчёте волн».
- **Часовики:** мелкий порог (<0,6 от авто) — в среднем убыток; устойчивый тренд лучше на 1ч и 1д.
- **Как робот выбирает бумаги** (20.10.2026): топ-50 по обороту (≥50 млн ₽/день), берёт каждый сигнал по порядку, пока есть деньги; при нехватке — пропуск. Пропускается: основной 86 из 368 сигналов, агрессивный 193 из 386 — в основном потому, что деньги заняты в открытых сделках (дней с 2+ сигналами всего ~65 за 7 лет).
- **Выбор «лучшего» сигнала при нехватке денег** (20.10.2026, `research/rank.js`): первым — по оценке подсчёта, по R:R, по ближнему/дальнему стопу, по обороту. Основной 25,5–27,2%/год, агрессивный 31,1–34,0% — всё внутри разброса случайного порядка (25,9–28,6 и 30,0–35,2), просадка одинаковая. **Не прошёл.** Слабый намёк: «оценка подсчёта выше — первой» сверху в обоих наборах и обеих половинах, но в пределах шума.
- **Лимит позиции 15–30% вместо 25%** (20.10.2026, `research/maxpos.js`, `research/maxpos_add.js`): основной — без разницы (26,2–26,8%/год; в лимит 25% упираются 9 сделок из 282). Агрессивный без доливок: 15% → 32,5 против 31,5%/год, просадка 11,7→10,7%, но вторая половина без выигрыша. Агрессивный с доливками: 15% → 34,4 против 32,9%/год, но половины противоречат (до 2023: 33,7 против 25,5; с 2023: 44,8 против 48,5), просадка 10,6→12,7%, серия убыточных 26→34. **Не прошёл, оставляем 25%.** Меньший лимит = больше сделок = длиннее серии; серии укорачивали фильтры (SMA200, безубыток), а не лимит.
- **Реальная доходность агрессивного с доливками ~33%/год** (лимит 25%, просадка ~11%), если доливку брать только при взятой основной сделке — как робот в приложении. Цифра ~38% выше получена, вероятно, когда доливки в портфеле считались отдельно от основной сделки (`wbp3.js`) — завышено. Сравнивать варианты на `maxpos_add.js`.

## Важные тонкости кода (на них уже наступали)

- **Дивиденды:** дневные свечи поправлены на дивиденды (`adjustDividends`); младшие свечи в тренажёре и догруженная старая история — тоже приводятся к той же шкале (`trAdjF`, `trHist.adj`). Иначе цена «прыгает».
- **Фоновая проверка:** у WebView без окна `web.post()` никогда не выполняется — ответы HTTP отдаются через `Handler(Looper.getMainLooper())`. Роботы ходят первыми, бумаги — не дольше 6 мин, журнал сохраняется после каждой бумаги, `lastbg.step` показывает, где остановилось.
- **Роботы:** настройки счёта `a.cfg` = набор; позиции, открытые до обновления настроек, ведутся по `a.cfgPrev` (`p.legacy`). Безубыток: `a.be` у счёта, `p.be` у позиции (позиция ведётся так, как открыта). Доход фонда ВИМ — отдельно (`a.mm`), в деньги робота не входит (2.27).
- **Тренажёр:** состояние сохраняется в файлы `trainer_state.json`/`trainer_bars.json`; ключи событий — по времени свечи, не по номеру (окно анализа сдвигается).
- Автопауза тренажёра по видам: сигналы, сделки системы, фигуры, «мои».
- **Темы оформления** (2.35): `SKINS` в app.js — меняют только CSS-переменные (`--bg`, `--bg2`, `--bg3`, `--line`, `--ink`, `--mut`, `--dim`, `--hud`, `--acc`, `--accl`) и цвета графика `K` (фон, сетка, ось, свечи, ярлык цены). Цвета сигналов (стоп, цель, волны, сделки) — общие для всех тем, их не трогать. В `draw()` для фона/сетки/свечей использовать `K.*`, а не жёсткие цвета. Строка состояния — `Android.setBarColor`.
- **Разработчик** — константа `DEV` в app.js (показывается в «Настройки → Данные → О приложении»).
- **Пояснения не прятать**: Егор просил не убирать объяснения под «подробнее», особенно в плане и входе в сделку. Длинный текст можно только разбивать на строки/пункты.
- В CSS уже есть класс `.chk` (значки в таблицах) — не использовать это имя для другого.
