# Волны Эллиотта

Android-приложение для анализа акций Мосбиржи по волновому принципу Эллиотта (книга Пректера и Фроста): разметка волн и фигур, сигналы, бэктест, тренажёр на истории, виртуальные роботы, уведомления. Данные — T-Invest API (токен только для чтения, хранится на телефоне).

Подробности, сборка и правила работы — в [CLAUDE.md](CLAUDE.md).
